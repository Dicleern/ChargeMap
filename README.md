# ChargeMap Europe

**European Electric Vehicle Adoption & Charging Infrastructure Analytics**

## Project Overview

ChargeMap Europe is an end-to-end data analytics and interactive web application project focused on exploring electric vehicle adoption and charging infrastructure across European countries.

## Project Objectives

- Analyze electric vehicle adoption trends across Europe.
- Examine charging infrastructure development.
- Compare countries using standardized indicators.
- Integrate data from multiple international sources.
- Develop an interactive React-based web application for data exploration.

## Technology Stack

- **Python:** Data profiling, cleaning, and exploratory analysis
- **SQL / Google BigQuery:** Data transformation and analytical queries
- **React:** Interactive frontend development
- **Git & GitHub:** Version control and project documentation

## Project Status

Phase 1 — Project Setup & Data Profiling

## Data Sources

Planned sources include IEA, Eurostat, OICA, and UN population datasets. Source details and methodological limitations will be documented as the project progresses.
